## Task 3 - Case 1
Symptom: Both guests have Internet, but can't reach each other

| # | Evidence | What it shows | What I conclude / rule out | Next|
| :--- | :--- | :--- | :--- |:--- |
|1| E2 | shows the ip of ubuntu | rule out ubuntu ip |check ip on windows |
|2| E4 | shows ip of windows | ruled out windows ip| check network adapters |
|3| E6 | turns on network adapter Ubuntu | network adapter was off |  turn on network adapter Ubuntu |
|4| E7 | turns on network adapter windows | network adapter was off | turn off the firewall  |
|5| E3 | allow ping by turning off the firewall| the firewall blocked the connection| check the ping |
|6| E1 | there is Internet connection in Ubuntu| results of ping | check connection on windows|
|7| E5 | there is Internet connection in Windows| results of ping | end |

ignored evidence: e8
missing evidence: ping windows to ubuntu
root cause: Windows Defender Firewall blocks incoming ICMP echo requests (ping) by default on new/Public network profiles
Fix: 
```
New-NetFirewallRule -DisplayName "Allow ping in (ICMPv4)" -Protocol ICMPv4 -IcmpType 8 -Direction Inbound -Action Allow
```
Verification: 
```ubuntu
ping -c 3 10.0.2.15
```
